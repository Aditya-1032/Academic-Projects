## Projects

### 1. वास्तुविस्ता (VastuVista) – Future Prospects in Real Estate Price Modelling

**Domain:** Real Estate Analytics  
**Objective:** Explore real estate price modelling using Bengaluru housing data and evaluate different regression techniques.

**Key Activities:**
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature engineering
- Outlier detection and treatment
- Multicollinearity analysis using VIF
- Regression modelling and performance comparison

**Technologies:** Python, Pandas, NumPy, Matplotlib, Scikit-learn

**Models Used:**
- Linear Regression
- Ridge Regression
- Support Vector Regression (SVR)

**Project Files:** Notebook, dataset and project presentation.
